Sujet

Traduire la parole,
en temps réel.

Une plateforme MLOps qui prend un audio en français, en extrait le texte, le traduit en anglais, ukrainien, espagnol ou allemand, et restitue une voix synthétisée dans la langue cible.

Trois modèles hétérogènes (STT + LLM + TTS) orchestrés en un pipeline observable, sécurisé et déployé en production sur traduction-audio.fr.

Besoin & problème

Info-trafic 107.7,
uniquement en français.

Constat

Les flash-infos autoroutiers d'Autoroute Info 107.7 (accidents, bouchons, travaux, fermetures) sont diffusés exclusivement en français.

Or les autoroutes françaises accueillent chaque année des millions d'usagers étrangers — tourisme, transport, transit européen.

Problème

Un chauffeur ukrainien, espagnol ou allemand ne comprend pas les alertes trafic diffusées → ne peut pas anticiper un accident, un bouchon, une fermeture.

Impact : sécurité routière, prévention des accidents secondaires, fluidité du trafic.

Produit

Une plateforme en ligne,
captation temps réel & traduction.

Ce qu'elle fait

  • Capte les flash-infos 107.7 en continu (zones nord / sud / ouest / est)
  • Extrait les événements par sévérité (accident, bouchon, animal…)
  • Traduit en 4 langues : EN, UK, ES, DE
  • Restitue en audio synthétisé — écoutable directement

Interfaces

  • Web public — upload d'un audio → traduction on-demand
  • Dashboard admin — flux live des flash-infos captés + filtres par sévérité
  • Bonus meeting recorder — feature émergée pendant le dev (voir slide 6)

Proposition de valeur

Pour qui,
pourquoi maintenant.

Utilisateurs

Chauffeurs étrangers sur autoroutes françaises · touristes, transporteurs, transit européen.

Opérateurs routiers (Vinci, APRR, Autoroute Info) — complément à leur diffusion mono-langue.

Enjeu

Prévention des accidents secondaires liés à l'incompréhension d'une alerte.

Fluidité du trafic — permet à un chauffeur non-francophone d'anticiper une déviation.

Pourquoi maintenant

L'IA générative (Whisper, LLMs multilingues, TTS neural) est enfin assez précise, rapide et abordable pour une chaîne temps réel.

Coût par traduction : < $0.001.

Fonctions de l'app

Quatre fonctionnalités.

01 · Upload

Traduction on-demand

Utilisateur upload un audio FR (MP3/WAV) → transcription + traduction + audio synthétisé. Choix de la langue cible via UI.

02 · Meeting

Enregistrement live & résumé

Feature émergée pendant le dev. Enregistrement micro live, transcription chunked, résumé LLM à la fin. Piste de monétisation SaaS.

03 · Admin

Dashboard MLOps

Métriques infra, expériences MLflow, DAGs Airflow, users, traces LLM, coûts. Accès role-based (is_admin).

04 · Watcher (backend)

Captation temps réel des flash-infos 107.7

Service backend qui poll autoroutes-info.fr, transcrit les nouveaux flash-infos, extrait les événements par sévérité (accident/bouchon/…) et les traduit dans les 4 langues. Alimente le dashboard admin en SSE.

Flow de la donnée

De l'audio FR
à l'audio traduit.

Chaque étape est instrumentée : latence, tokens, coût $, tracing MLflow + Langfuse. Deux garde-fous sécurité : anti-injection sur l'entrée, anti-hallucination sur la sortie.

Stack — Interface

Next.js 15,
standalone.

Rôle

Framework React avec SSR/SSG, rendu output: standalone pour Docker minimal. Rewrites internes vers les services backend — évite d'exposer plusieurs ports publics.

Middleware pour l'auth JWT côté edge, redirection automatique vers /login.

Comparé à

  • Vue.js écosystème plus petit, moins de composants tiers
  • Angular overkill pour un frontend de cette taille
  • Next.js ✓ SSR natif, hot reload, standard industrie, image Docker < 250 Mo

Stack — Backend microservices

FastAPI
sur les 6 services.

Rôle

Framework Python asynchrone pour construire des APIs REST. Validation automatique via Pydantic, OpenAPI/Swagger généré automatiquement, support natif async/await.

Utilisé sur les 6 services : Gateway, Pipeline, STT, LLM, TTS, Watcher.

Comparé à

  • Flask synchrone, pas de validation typée native
  • Django monolithique, trop lourd pour du microservice
  • Express.js Node — obligerait à réécrire toute la logique ML en JS
  • FastAPI ✓ async natif, Pydantic, OpenAPI auto, perf 3× Flask

Stack — Orchestration LLM

LangChain LCEL.

Rôle

Chaînage typé des 3 étapes du pipeline (STT → LLM → TTS) via l'opérateur |. Chaque étape est un Runnable composable, testable, instrumenté. 

# LCEL — 3 étapes composées
pipeline = (
    RunnableLambda(_stt_step)
    | RunnableLambda(_llm_step)
    | RunnableLambda(_tts_step)
)

Comparé à

  • LangGraph overkill pour un flow linéaire (pas de branching)
  • Custom Python chaque étape écrite à la main, pas d'instrumentation gratuite
  • Haystack plus orienté RAG que pipeline générique
  • LCEL ✓ typage, composabilité, tracing Langfuse gratuit, standard

Stack — Abstraction LLM

LiteLLM
provider-agnostic.

Rôle

Une seule API qui route vers Groq, OpenAI, Anthropic, Ollama, Mistral, etc. selon le préfixe du nom de modèle. Pricing intégré, gestion des tokens et coûts automatique.

Preuve concrète : quand Groq a déprécié llama-3.1-8b-instant en août 2026, migration vers OpenAI en changeant une seule variable d'environnement — zéro ligne de code touchée.

Comparé à

  • SDK OpenAI direct vendor lock-in, impossible de switcher
  • LangChain LLM wrappers couplés à l'écosystème LangChain
  • Portkey / OpenRouter ajoute un hop réseau, latence +100ms
  • LiteLLM ✓ 100+ providers, pricing intégré, cost tracking natif

Modèle — Speech-to-Text

Faster-Whisper
large-v3.

Rôle

Transcription audio multilingue (99 langues supportées). Version large-v3 d'OpenAI, servie via faster-whisper (implémentation CTranslate2 optimisée). large-v3 en prod (3 Go), small pour le meeting live (250 Mo).

Détection automatique de la langue source → paramètre language_probability utilisé pour rejeter les audios non-français.

Comparé à

  • OpenAI Whisper API coût $0.006/min, pas de contrôle sur la version
  • Google Speech-to-Text $0.024/min, moins précis en FR technique
  • AssemblyAI $0.015/min, précis mais cher à l'échelle
  • Faster-Whisper ✓ auto-hébergé, gratuit, 4× plus rapide que Whisper Python vanille

Modèles — Traduction

OpenAI GPT-4o mini,
en fallback multi-provider.

Rôle

LLM de traduction FR → EN/UK/ES/DE. Défaut prod openai/gpt-4o-mini (pay-as-you-go). Fallback dispo sur Groq (free tier) et Anthropic Claude.

Choix data-driven — comparé sur 30 flash-infos golden :

Llama 8B · v1.0
40.2
Llama 8B · v1.1 retenu prod
46.2
Llama 70B · v1.1 champion BLEU
51.3

Champion BLEU = 70B, mais retenu prod = 8B (70B coûte 10× plus pour +5 pts).

Comparé à

  • Modèles locaux (Ollama) gratuit mais latence 10-30s, qualité inférieure
  • Anthropic Claude Haiku excellent mais 2× plus cher qu'OpenAI mini
  • DeepL API spécialisé traduction, mais boîte noire non pilotable par prompt
  • OpenAI GPT-4o mini ✓ pay-as-you-go, latence < 2s, $0.0005/traduction, prompts custom

Modèle — Text-to-Speech

Voxtral (Mistral)
+ MMS local par langue.

Rôle

Synthèse vocale avec routing intelligent selon la langue cible :

  • EN / ES / DE / FR → Mistral Voxtral (MP3, voix naturelle)
  • UK (ukrainien) → MMS-TTS local de Meta (WAV, voix native)

Pourquoi ce split : Voxtral n'est pas entraîné en ukrainien → voix anglaise avec accent. MMS-TTS a un modèle mms-tts-ukr natif.

Comparé à

  • OpenAI TTS excellent mais cher ($15/1M chars), pas de UK
  • ElevenLabs qualité premium, prix élevé, pas de UK avant fin 2026
  • Google TTS couvre l'UK mais voix robotique
  • Voxtral + MMS ✓ qualité pro sur langues supportées + fallback natif pour UK

Infrastructure — Container orchestration

Docker Compose,
pour 14 services.

Rôle

Orchestre 14 conteneurs sur une seule machine : frontend, 6 microservices FastAPI, MLflow, Grafana, Prometheus, Airflow (scheduler + webserver + postgres).

Réseau Docker interne isolé — services bindés sur 127.0.0.1, seul nginx expose le port public.

Comparé à

  • Kubernetes overkill (14 services sur 1 machine) — courbe d'apprentissage 6 mois
  • Docker Swarm abandonné par la communauté, écosystème mort
  • Nomad (Hashicorp) peu répandu, moins de tutos
  • Compose ✓ un fichier YAML, up --build, healthchecks natifs, standard démo

Infrastructure — Edge

Nginx +
Let's Encrypt SSL.

Rôle

Reverse proxy HTTPS sur traduction-audio.fr. Certificats Let's Encrypt renouvelés automatiquement via certbot. Basic-auth au niveau edge en fallback.

Config découpée : traudio.conf (server + SSL) + traudio-proxy.conf (headers proxy réutilisables).

Comparé à

  • Traefik config dynamique via labels Docker, moins lisible
  • Caddy HTTPS auto mais écosystème plus petit, moins de tutos ops
  • Apache config verbose, moins performant en reverse proxy
  • Nginx ✓ maturité 20 ans, config lisible, benchmarks de référence

Sécurité — Authentification

JWT custom,
rotation refresh.

Rôle

Access token JWT HS256 15 min + refresh token aléatoire 7 jours hashé SHA-256 en DB. Rotation obligatoire à chaque refresh (ancien révoqué).

25 tests unitaires couvrant : bcrypt, roundtrip JWT, expiration, tampering, wrong signature, wrong algorithm.

Comparé à

  • Auth0 $23/mois minimum, dépendance externe critique
  • Firebase Auth vendor lock-in Google, quotas gratuits serrés
  • Keycloak puissant mais 1 GB RAM, overkill pour ce projet
  • JWT custom ✓ zéro dépendance, contrôle total, testable, 100 lignes de code

Data engineering — Batch

Apache Airflow,
nightly eval.

Rôle

Orchestrateur de workflows. DAG nightly_golden_eval qui tourne à 02:00 UTC : traduit le corpus golden, calcule les métriques BLEU/METEOR, agrège, détecte les dérives.

Stack complète : scheduler + webserver + PostgreSQL dédié. Interface web sur :8080.

Comparé à

  • Prefect API plus moderne mais moins répandu en entreprise
  • Dagster excellent modèle de données mais courbe d'apprentissage
  • cron simple pas de monitoring, retries, dépendances entre tâches
  • Airflow ✓ standard entreprise, compétence transférable, écosystème mature

MLOps — Hub

MLflow
tracking · eval · tracing.

Tracking

12 configurations comparées (2 Whisper × 2 LLM × 3 prompts) × 5 audios golden = 60 runs. Métriques BLEU/METEOR/WER/latence/coût. Tag champion auto sur meilleur BLEU. Model Registry avec 3 modèles taggés production_version. Runs pré-migration OpenAI (Groq Llama à l'époque).

Evaluation

mlflow.evaluate() — 8 métriques natives : BLEU, ROUGE-1/2/L, exact_match, toxicity, Flesch-Kincaid, ARI. log_table per-audio (drill-down cliquable).

Tracing

Décorateurs @mlflow.trace sur les 3 steps du pipeline LangChain. Spans hiérarchiques STT → LLM → TTS visibles dans l'UI. Opt-in via env var.

Comparé à

  • Weights & Biases excellent mais SaaS payant après quota gratuit
  • ClearML puissant mais moins standardisé en France
  • MLflow ✓ open-source, self-hosted, gratuit, standard Databricks/AWS

Observability — Tracing LLM

Langfuse,
spans hiérarchiques.

Rôle

Capture chaque appel LLM avec input/output/latence/coût/tokens. Vue waterfall des spans du pipeline (STT + LLM generation + TTS).

Intégré au pipeline via 1 client init + 4 spans par requête. Cloud hosted (cloud.langfuse.com) avec option self-hosted possible.

Comparé à

  • LangSmith couplé à LangChain, moins ouvert
  • Arize Phoenix excellent mais orienté enterprise
  • Helicone proxy HTTP intrusif
  • Langfuse ✓ open-source, self-hostable, pricing raisonnable, UI moderne

Architecture

14 microservices,
un seul réseau.

14 conteneurs Docker — 6 microservices FastAPI (Gateway, Pipeline, STT, LLM, TTS, Watcher) + Frontend Next.js + MLflow + Prometheus + Grafana + 3 conteneurs Airflow (Scheduler, Webserver, Postgres) + Airflow-init (éphémère). Nginx sur le host, Langfuse en cloud externe. LLM proxifie 3 providers cloud (GROQ, OpenAI, Anthropic) via LiteLLM. Meeting et Live passent en direct par le Gateway (STT + LLM pour Meeting, OpenAI Realtime WebRTC pour Live). Survole chaque bloc pour voir les détails.
